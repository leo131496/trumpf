# 通快客户积分中心 Demo

在线演示：https://leo131496.github.io/trumpf/

整体使用通快蓝 `#0066FF`、深灰 `#20252D`、白色 `#FFFFFF` 三种基础色，通过透明度呈现层级。原始需求截图与客户提供的图片保留原样。

## 查看方式

直接访问上方演示地址，或下载仓库后打开 `index.html`。无需安装依赖。

- 桌面支持双屏演示、小程序演示、运营后台三种模式。
- 手机默认进入小程序，可在顶部切换运营后台。
- 包含个人与企业身份、积分明细与规则、内容分享、活动邀约、商城兑换、订单，以及配套运营流程。
- 企业备件券支持选择兑换数量，使用中英文逗号分隔机床号；数量须一致；点击确认时校验未填机床号及数量不一致并提示，按顺序逐件对应，总积分随数量计算，订单及后台发货记录同步展示。
- 企业备件券兑换订单自动进入发货列表；运营人员按订单编辑补全备件券信息，订单号、企业、数量和全部机床号自动同步，支持多笔订单分别发货。
- 扫码审核的“查看”仅展示详情；审批动作与详情查看独立。二维码预览不提供模拟扫码，发货页不提供手动新增订单。
- 分享凭证审核采用两级页面：一级按活动名称查询活动，支持新建、详情和编辑；二级按活动审核凭证，保留图片预览、完整详情和单条/批量审核。视频号来源必填视频号ID，公众号来源必填活动链接；支持文本分享渠道和起止日期。列表和表单使用状态开关，开启的活动须先关闭才可编辑；保存或切换状态时同步记录更新人与更新时间。
- 小程序“内容分享”展示后台已开启且已开始的活动，无独立新增凭证入口。每条活动提供详情和补全凭证，支持实际选择、预览及删除 JPG、PNG、WEBP 图片，最多 9 张；提交与驳回重提均关联原活动，后台可查看真实附件并审核。当前用户的状态与其他用户隔离，支持待补全、审核中、审核通过、审核驳回、已过期筛选；过期后停止补全，已提交待审核或审核通过的记录保留审核状态。活动关闭后不在小程序展示。
- 活动列表和详情使用与来源对应的单一卡片：公众号显示“微信公众号文章 / 打开文章”，视频号显示“微信视频号动态 / 打开视频号”，不展示原始网址或视频号ID。文章按钮打开后台配置的地址；网页 Demo 的视频号按钮提示在微信小程序中打开，不模拟真实唤起成功。
- 页面中的图片使用独立资源并按需加载，HTML 从约 5.4 MB 缩减至约 0.33 MB。离线使用时请完整解压并保留 `assets` 文件夹。
- 所有数据与授权、审核、发货操作均为浏览器中的交互演示，不连接真实业务系统；刷新页面后恢复示例数据。

## 交互回归检查

在已安装 Playwright 和 Chromium 的 Node.js 环境运行 `node tests/share-activities.cjs`，可检查活动管理、表单校验、按活动隔离审核、图片及详情和桌面/手机布局。运行 `node tests/content-sharing.cjs` 检查前后台活动联动、五种状态、真实图片上传、审核与驳回重提等流程。均可追加 Demo URL 验证线上版本；内容分享检查可使用 `PLAYWRIGHT_CHANNEL=chrome` 选择已安装的 Chrome。
