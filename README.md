# 通快客户积分中心 Demo

在线演示：https://leo131496.github.io/trumpf/

整体使用通快蓝 `#0066FF`、深灰 `#20252D`、白色 `#FFFFFF` 三种基础色，通过透明度呈现层级。原始需求截图与客户提供的图片保留原样。

## 查看方式

直接访问上方演示地址，或下载仓库后打开 `index.html`。无需安装依赖。

- 桌面支持双屏演示、小程序演示、运营后台三种模式。
- 手机默认进入小程序，可在顶部切换运营后台。
- 包含个人与企业身份、积分明细与规则、分享凭证、活动邀约、商城兑换、订单，以及配套运营流程。
- 企业备件券支持选择兑换数量，使用中英文逗号分隔机床号；数量须一致；点击确认时校验未填机床号及数量不一致并提示，按顺序逐件对应，总积分随数量计算，订单及后台发货记录同步展示。
- 企业备件券兑换订单自动进入发货列表；运营人员按订单编辑补全备件券信息，订单号、企业、数量和全部机床号自动同步，支持多笔订单分别发货。
- 扫码审核的“查看”仅展示详情；审批动作与详情查看独立。二维码预览不提供模拟扫码，发货页不提供手动新增订单。
- 分享凭证审核采用两级页面：一级按活动名称查询活动，支持新建、详情和编辑；二级按活动审核凭证，保留图片预览、完整详情和单条/批量审核。活动可配置服务号或公众号来源、链接、文本分享渠道、起止日期及开启/关闭状态，保存后更新列表。
- 所有数据与授权、审核、发货操作均为浏览器中的交互演示，不连接真实业务系统；刷新页面后恢复示例数据。

## 交互回归检查

在已安装 Playwright 和 Chromium 的 Node.js 环境运行 `node tests/share-activities.cjs`，可检查活动管理、表单校验、按活动隔离审核、图片及详情和桌面/手机布局。可追加 Demo URL 验证线上版本。
