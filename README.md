# 通快客户积分中心 Demo

在线演示：https://leo131496.github.io/trumpf/

整体使用通快蓝 `#0066FF`、深灰 `#20252D`、白色 `#FFFFFF` 三种基础色，通过透明度呈现层级。原始需求截图与客户提供的图片保留原样。

## 查看方式

直接访问上方演示地址，或下载仓库后打开 `index.html`。无需安装依赖。

- 桌面支持双屏演示、小程序演示、运营后台三种模式。
- 手机默认进入小程序，可在顶部切换运营后台。
- 包含个人与企业身份、积分明细与规则、分享凭证、活动邀约、商城兑换、订单，以及配套运营流程。
- 企业备件券支持选择兑换数量，使用中英文逗号分隔机床号；数量须一致；点击确认时校验未填机床号及数量不一致并提示，按顺序逐件对应，总积分随数量计算，订单及后台发货记录同步展示。
- 所有数据与授权、审核、发货操作均为浏览器中的交互演示，不连接真实业务系统；刷新页面后恢复示例数据。
